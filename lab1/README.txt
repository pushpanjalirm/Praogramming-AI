Lab1 implementation

Files:
- tictactoe.py  : Interactive Tic-Tac-Toe (human X vs AI O)
- demo_ai_vs_ai.py : Non-interactive demo where X is random and O is AI (minimax)

How to run (PowerShell):
1. Activate venv: .\venv\Scripts\Activate.ps1
2. Run demo: python .\lab1\demo_ai_vs_ai.py
3. Or run interactive game: python .\lab1\tictactoe.py

Notes: No external libraries required.
