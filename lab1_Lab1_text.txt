2 Theoretical Background
2.1 Minimax Algorithm
The Minimax algorithm is a decision-making algorithm used in two-player games. It assumes
that both players play optimally and aims to minimize the possible loss for the worst-case
scenario. The algorithm recursively evaluates all possible moves, building a game tree where:
•MAX player (AI) aims to maximize the score
•MIN player (human) aims to minimize the score
•Terminal states have values: +1 (AI wins), -1 (human wins), 0 (draw)
